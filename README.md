# VR Nursing Lab — sitio estático

Sitio web estático (sin backend, sin build) listo para publicarse en GitHub Pages o cualquier hosting estático.

## Estructura de archivos

```
vr-nursing-lab-site/
├── index.html
├── README.md
└── assets/
    ├── css/styles.css
    ├── js/app.js
    └── img/
        ├── udec-logo.png
        └── fucs-logo.png
```

**Archivo principal: `index.html`**.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta manteniendo la misma estructura.
3. Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
4. Guarda; GitHub te dará una URL `https://tu-usuario.github.io/tu-repositorio/`.

## Notas

- Progreso guardado en `localStorage` del navegador (por dispositivo).
- Paleta 100% verde claro (sidebar y encabezado ya no usan fondo oscuro), sin ningún tono azul, y sin emoji.
